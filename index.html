kube-llmops

Kubernetes-native LLMOps Platform — Deploy, manage, monitor, and optimize your entire LLM infrastructure with one command.

GitHub → Quick Start

🚀 What's Inside

🧠 Model Serving

vLLM, llama.cpp, TEI — auto-selected based on model format. Engine auto-detection from source name.

🛠️ kubectl CLI Plugin

15+ imperative commands: deploy, list, scale, canary, logs, test, finetune, rag, migrate and more.

🔑 AI Gateway

LiteLLM unified API, key management, rate limiting, budget control per team.

📊 Observability

11 Grafana dashboards + 8 alert rules + Langfuse v3 LLM tracing with full prompt visibility.

⚡ KEDA Autoscaling

Scale based on queue depth, TTFT P95, TPOT P95. Supports scale-to-zero with fallback.

🔒 Enterprise Security

Keycloak SSO, LLM-Guard prompt injection defense, NetworkPolicy isolation.

📚 RAG Infrastructure

Dify platform + pgvector + TEI embedding/reranking + Ragas evaluation + quality gate.

🎯 Fine-tuning

LLaMA-Factory LoRA/QLoRA/Full + Argo Workflows pipeline + MLflow tracking.

⚡ Quick Start

$ helm install kube-llmops charts/kube-llmops-stack \
  -f charts/kube-llmops-stack/values-single-node.yaml \
  --set global.nodePort.enabled=true

$ curl http://litellm.llmops.local/v1/chat/completions \
  -H "Authorization: Bearer sk-kube-llmops-dev" \
  -d '{"model":"qwen2-5-0-5b","messages":[{"role":"user","content":"Hello!"}]}'
